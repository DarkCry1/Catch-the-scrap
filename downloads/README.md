# Catch the Scrap v0.7

1. Open [Catch-the-scrap-v0.7.rbxl](Catch-the-scrap-v0.7.rbxl) on GitHub.
2. Click **Download raw file** (the down-arrow button).
3. Stop the old Studio test and open this file with **File → Open from File / Ctrl+O**.
4. Press **Play / F5**. The world is constructed at startup.

Characters raise their arms to carry salvage overhead. Deposit scrap to watch
a twin-shaft shredder pull it in, crush it and throw sparks/offcuts. Find sealed
cardboard robot boxes in all seven districts and bring them home: a box opens
on a free platform and reveals a ready-made robot after 3.8 seconds.

**WASD** move · **Hold E** recover/deliver/browse · **Q** drop · **X** close shop.
A robot box needs one free platform. Four total platforms; session-only progress.
All custom in-game text is English.
