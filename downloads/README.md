# Catch the Scrap v1.12 — Original background music

The game continues from the user's uploaded **v1.11**. The new original
80-second loop **Scrapyard Afterglow** is supplied under CC0, with no third-party
samples. Music fades in, ducks under warnings/cinematics and pauses/resumes with M.

- [Listen/download MP3](Scrapyard-Afterglow.mp3)
- [Download WAV for Roblox upload](Scrapyard-Afterglow.wav)
- [Prepared v1.12 place](Catch-the-scrap-v1.12.rbxl)
- [Editable source, composer, license and MP3](Catch-the-scrap-v1.12-source.zip)

**The music audio asset ID is not configured yet.** The owner must upload the
supplied recording to Roblox, grant the experience permission and set
SoundService.ScrapyardMusic.SoundId. The local WAV/MP3 cannot be embedded into a
place as playable audio. This workspace has no authenticated Roblox upload tool.

[Swedish upload/setup guide](../docs/BACKGROUND_MUSIC_SV.md) ·
[Studio guide](../docs/STUDIO_START_SV.md) · [CC0/source notice](../assets/music/README.md)

Stop old Play, open the new place with Ctrl+O, configure the approved audio ID,
then F5. The existing v1.11 progression, guards and effects are retained. Both
place formats and automated checks pass; actual music playback still needs
Roblox upload/approval and a Studio listening test. Older downloads are snapshots.
