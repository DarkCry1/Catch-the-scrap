# Catch the Scrap v0.2 – verkstäder och robotar

1. Öppna [Catch-the-scrap-v0.2.rbxl](Catch-the-scrap-v0.2.rbxl) på GitHub.
2. Klicka på **Download raw file** (nedåtpilen) vid filen.
3. Spara filen på din Windows-dator.
4. I Roblox Studio väljer du **File → Open from File…** eller **Ctrl+O** och öppnar den nya filen.
5. Tryck **Play / F5**. Kartan och verkstäderna skapas när spelet startar.

**WASD**: gå. **Håll E** nära ett fynd: plocka upp. **Q**: släpp. Gå in i din egen verkstad och **håll E vid maskinen med orange kant**: lämna in.

Varje fynd ger **1 scrap**. **10 scrap → en Scrap Bot MK-I → $5/sek**. Roboten byggs synligt del för del. Fyra robotplatser ger som mest **$20/sek**. Pengar, scrap och robotar gäller enbart aktuell spelsession.
