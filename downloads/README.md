# Catch the Scrap v1.0

1. Download [Catch-the-scrap-v1.0.rbxl](Catch-the-scrap-v1.0.rbxl) with **Download raw file**.
2. Stop the old Studio test. Open this file with **Ctrl+O**, then **Play / F5**.
3. Open **I / Details → Robot Index** to browse ten chassis per rarity and select
   your next build. At your own machine, **Your Platforms** can retire completed
   robots to free slots; discoveries remain for this visit.
4. Use **F4 / Admin** to test Epic, Legendary or Celestial box events in Stage 1.
   Deposit a box at home for its cinematic. **Space / Skip Camera** restores view.

Epic is purple, Legendary gold and Celestial has animated RGB borders and
opening effects. Higher tiers add 3D energy rings, orbiting crystals, holograms
and an owner-only camera. Rare+ chassis include build-only and box-only models.
The index has **70 entries**: ten original geometries across seven rarities.

**Cash, robots and discoveries remain session-only.** Admin includes UserId
11824623188, local Studio tests and the personal experience owner.
