# Catch the Scrap v1.5 — Stage Guardians

1. [Download Catch-the-scrap-v1.5.rbxl](Catch-the-scrap-v1.5.rbxl) using **Download raw file**.
2. Stop old Studio Play, open the new place with **Ctrl+O**, then **Play/F5**.
3. Enter Common empty-handed, then pick up its scrap near the guardian. It warns
   before chasing. Drop with Q or escape the district; only carried loot is at risk.

Seven walking guardians replace the old drone groups, with one robot in every
rarity district. Chase speed increases 15→31 studs/sec and model height 8.4→17.9
studs. These are original test-balance values, not verified Steal An Egg values.

The game continues from the user's v1.4, preserving Robotdex (61 species),
saving with DataStore fallback, six/eight platforms, mutations, rebirth, quests,
carrying and audiovisual effects. The exact uploaded v1.4 place is archived here.
